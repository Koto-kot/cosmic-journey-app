# Product Overview

## Working name
**Cosmic Journey**

Alternative brand direction: **370**

## One-sentence concept
A smartphone app that shows, in real time, how long and how far a person has travelled through space since birth.

## Core insight
A person may feel stationary, but Earth is constantly moving.

The app turns that invisible motion into something visible:
- kilometres continuously increase;
- seconds continuously increase;
- days accumulate.

The emotional effect comes from watching the journey continue without doing anything.

## Main screen
The main screen should feel almost meditative.

It shows only:

### Distance
`674 218 493 771.842 km`

### Days
`20 948 DAYS`

### Total seconds
`1 809 907 218.742 SECONDS`

A small menu button opens all secondary features.

## Product philosophy
This is not primarily an astronomy encyclopaedia.
It is not primarily an age calculator.
It is a personal live odometer for a journey through the Universe.

## Onboarding

### Step 1 — show the effect first
Show a live increasing distance.

Then ask:
**How far have you travelled?**

### Step 2 — minimum input
Ask:
**When did your journey begin?**

Allow the user to start with only a birth year.
Immediately show an approximate result.

### Step 3 — optional precision
Offer:
**Make it more precise**

Optional:
- month;
- day;
- birth time.

No account required.

If implemented as planned:
**Your birth date stays on this device.**

## Free version
Includes:
- live distance;
- days;
- total seconds;
- onboarding;
- base style;
- basic milestones;
- science explanation;
- local settings;
- offline operation.

## Advertising
Free iOS/Android builds may show banners via `AdSlot` only:
- never on the main live screen;
- never as launch interstitials;
- only at the bottom of Menu, Science, Styles, Statistics;
- Pro removes ads.

How payouts work: `docs/MONETIZATION.md`. GitHub Pages web preview has no ads.

## Milestones
Possible presets:
- 10 million km;
- 100 million km;
- 1 billion km;
- major round-number totals.

The app may show the next milestone and estimated time to reach it.

## Scientific positioning
Do not imply a known centre of the Universe.

The displayed value is an estimated path length relative to a selected physical reference frame.

Base mode may use a simplified CMB-relative average.
Future Scientific Mode may use a time-varying vector model.

## Brand feeling
- calm;
- endless;
- precise;
- cosmic;
- personal;
- minimal;
- alive;
- scientific;
- contemplative.

## Visual direction
- near-black background;
- subtle star field/depth;
- large typography;
- minimal labels;
- smooth number motion;
- no clutter.

The numbers are the hero visual.

## MVP success criterion
A first-time user can:
1. open the app;
2. understand the idea quickly;
3. enter a birth year;
4. see their journey immediately;
5. watch the numbers move;
6. close the app;
7. return later and see correct updated values.

Key qualitative test:
**Does the user want to keep looking at the moving numbers?**
